# powercode-py 脚手架 + 第 1 阶段（一问一答）Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 搭建 `powercode-py` 项目骨架，实现第 1 阶段"一问一答"：`powercode "prompt"` 调用 DeepSeek 返回回复。

**Architecture:** 纯手搓、无框架。`config.py` 加载配置，`chat.py` 封装 OpenAI 兼容 SDK，`cli.py` 提供入口。后续 7 个阶段在此骨架外延（工具、循环、压缩、计划、恢复、LangGraph）。

**Tech Stack:** Python 3.10+、`openai` SDK、`pytest`、`argparse`（stdlib）、服务器用 `uv` 管理。

**Spec:** `powercode-py-设计文档.md`（项目根目录）

## 开发与验证工作流

1. 本地写完代码 → `scp` 上传到服务器 `/data/home/hermes/projects/powercode-py/`

## Global Constraints

- Python ≥ 3.10（服务器实测 3.10.12）
- 包名 `powercode_py`，PyPI 名 `powercode-py`，CLI 命令 `powercode`
- 配置走 `provider.json`（gitignore，含真实 key），模板 `provider.json.example`（不含 key）
- `provider.json` 沿用原作者字段名：`baseURL` / `apiKey` / `model`（camelCase），Python 侧映射为 snake_case
- DeepSeek baseURL `https://api.deepseek.com`，OpenAI 兼容 SDK
- 代码注释 / docstring / 报错信息一律中文
- 每个任务结尾一个 commit（Conventional Commits），对应博客一个"跟做步骤"

## Review Focus

以下输入/失败模式是 spec 隐含但单元测试可能漏掉的，最可能咬到读者，各配一条测试钉进对应任务：

- [ ] **Step 1: 写失败测试**（4 个用例）

def test_load_valid_config(tmp_path):
    p = tmp_path / "provider.json"
    p.write_text('{"baseURL":"https://api.deepseek.com","apiKey":"sk-test","model":"deepseek-v4-flash"}', encoding="utf-8")
    c = load_config(p)
    assert (c.base_url, c.api_key, c.model) == ("https://api.deepseek.com", "sk-test", "deepseek-v4-flash")

def test_missing_file(tmp_path):
    with pytest.raises(ConfigError): load_config(tmp_path / "nope.json")

def test_malformed_json(tmp_path):
    p = tmp_path / "provider.json"; p.write_text("{not json", encoding="utf-8")
    with pytest.raises(ConfigError): load_config(p)

def test_missing_field(tmp_path):
    p = tmp_path / "provider.json"; p.write_text('{"baseURL":"x"}', encoding="utf-8")
    with pytest.raises(ConfigError): load_config(p)
